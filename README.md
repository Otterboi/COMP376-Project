# How to run the the game in unity:
1. Make sure the version of unity installed is `2022.3.46f1`
2. Open Unity Hub and find the project folder and open it.
3. Move to the `Scenes` folder and open the `Main Menu` scene.
4. Press on the play button in the editor and enjoy our game.
